# EnyFlow Landing Page

Een moderne, responsieve landingspagina voor de EnyFlow app - een applicatie die gebruikers helpt hun energiebalans te begrijpen en met vertrouwen te bewegen.

## 📋 Overzicht

Deze landing page presenteert EnyFlow met een visueel aantrekkelijke hero sectie, download buttons voor App Store en Google Play, en een mockup van de app interface.

## ✨ Features

- **Responsive Design**: Volledig responsive voor desktop, tablet en mobiel
- **Moderne UI**: Schone, moderne interface met gradient achtergronden
- **Download Links**: Knoppen voor App Store en Google Play downloads(werken niet)
- **App Mockup**: Visuele presentatie van de app in een telefoon mockup

## 🚀 Project Structuur

- `index.html` - Hoofdpagina
- `style.css` - Styling en responsive design
- `logo.png` - EnyFlow logo
- `mockup-png` - App afbeedling voor de mockup
- `README.md` - Dit bestand
